# xeval.js

Bibliotheque d'injection dynamique JS, HTML et CSS.

## Structure

- `src/xeval.ts` : source principal TypeScript
- `dist/` : builds generes automatiquement
- `docs/examples/` : exemples d'utilisation
- `tests/` : tests par moteur

## Scripts

- `npm test` : lance les tests Node
- `npm run build` : bundle Rollup + generation des declarations TypeScript
